# Manta Enterprise — Landing Page

Marketing site for [Manta Enterprise](https://mantacron.github.io/manta-enterprise/), the commercial AI engineering governance pipeline built by [Mantacron](https://github.com/mantacron).

## What it covers

- What Manta Enterprise does and why it exists
- The four capability pillars: compliance, risk & governance, security depth, spec & architecture
- Who it's built for (regulated industries, teams >10 engineers)
- Time and cost savings vs. hiring the equivalent specialist team
- Contact form for enterprise inquiries

## Stack

Static HTML/CSS — no build step, no dependencies. Edit `index.html` directly.

## Deploying

Served via GitHub Pages from this folder. Push to `main` and it updates automatically.

```bash
git add landing-page/
git commit -m "chore: update landing page"
git push
```
